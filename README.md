# YouTube Clone – Azure DevOps CI/CD Project

## Project Overview
This is a hands-on learning project focused on deploying a YouTube Clone application to Azure App Service using Azure DevOps CI/CD pipelines.

## What I Implemented
- Forked and cloned the source code from GitHub.
- Configured the application by following the project implementation steps.
- Practiced CI/CD workflows using Azure DevOps Classic and YAML pipelines.
- Configured the deployment workflow for Azure App Service.
- Tested the deployment and troubleshot issues encountered during implementation.

## Technologies Used
- Microsoft Azure
- Azure DevOps
- Classic Build and Release Pipelines
- YAML Pipelines
- Git and GitHub
- Azure App Service

## Learning Outcomes
- Understanding CI/CD pipeline workflows.
- Practicing application deployment to Azure App Service.
- Troubleshooting pipeline and deployment issues.
